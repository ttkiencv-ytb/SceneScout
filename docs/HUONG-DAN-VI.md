# SceneScout — Hướng dẫn nhanh (tiếng Việt)

## Cài đặt (bản app, không cần Python)
- **Mac**: tải `SceneScout-mac-apple-silicon.dmg` ở trang Releases → mở file → kéo SceneScout vào thư mục Applications. Lần đầu mở bị chặn: vào **Cài đặt hệ thống → Quyền riêng tư & Bảo mật → Vẫn mở**.
- **Windows**: tải `SceneScout-windows.zip` → giải nén → bấm đúp `SceneScout.exe`. Nếu hiện "Windows protected your PC": bấm **More info → Run anyway**.

## Dùng
1. Chọn hồ sơ (mỗi người một hồ sơ).
2. **Cài đặt** (một lần): thêm AI (ChatGPT / Claude / Gemini / DeepSeek, hoặc Gemini, Groq, OpenRouter miễn phí), dán khóa Pexels / Pixabay / Unsplash nếu có. Không có API thì dùng chế độ **Chat AI**.
3. **+ Dự án mới** → chọn file SRT → chọn AI qua API, Chat AI, hoặc Nhanh.
4. Duyệt ảnh: phím 1–5 chọn và sang dòng sau; T đổi tab; Space xem lớn; G / V mở Google / Envato rồi kéo ảnh vào; A / E đánh dấu cần ảnh AI / Envato.
5. **Xuất ảnh**: thư mục ảnh theo timecode + video MP4 dựng sẵn (kéo vào CapCut ở 0:00 cùng giọng đọc).

Dự án tự lưu. Chuyển dự án cho người khác: **Tải file** ở trang Dự án, người nhận bấm **Nhập file dự án**.
